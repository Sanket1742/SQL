## 🚀 Getting Started

### Prerequisites

- MySQL Server
- MySQL Workbench (Recommended)
- OR XAMPP / WAMP
- Any SQL-compatible IDE

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/sql-practice.git
```

2. Open MySQL Workbench.

3. Create a database.

```sql
CREATE DATABASE sql_practice;
USE sql_practice;
```

4. Open any `.sql` file.

5. Execute the script.
